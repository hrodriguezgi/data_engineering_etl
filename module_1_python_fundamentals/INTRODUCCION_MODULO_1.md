## Módulo 1: Python Fundamentals para Data Engineering

## 1. Apertura de la sesión

Bienvenidas y bienvenidos al **Módulo 1: Python Fundamentals**.

Este espacio está diseñado para construir una base técnica sólida en Python, enfocada específicamente en el trabajo real de **Data Engineering**. Durante el módulo no solo veremos sintaxis: vamos a conectar cada concepto con tareas que ocurren en pipelines de datos reales.

La meta es clara: que cada persona pueda salir de este módulo con la capacidad de **leer, entender, modificar y crear scripts de Python** que resuelvan problemas de extracción, transformación, validación y carga de datos.

---

## 2. Contexto: ¿Por qué Python en Data Engineering?

Python es uno de los lenguajes más usados en ingeniería de datos porque combina tres cosas clave:

1. **Velocidad de desarrollo**
   Permite construir soluciones funcionales en menos tiempo.

2. **Legibilidad y mantenimiento**
   Su sintaxis facilita que los equipos colaboren y mantengan código en el tiempo.

3. **Ecosistema robusto**
   Se integra con archivos, APIs, bases de datos y librerías del ecosistema de datos.

En términos prácticos, Python suele estar en el centro de procesos ETL donde se requiere transformar datos de manera confiable y repetible.

## 3. Qué vamos a cubrir en este módulo

Este módulo está organizado para avanzar en complejidad de forma progresiva:

### Lección 00: Introducción a Python para Data Engineering
- Rol de Python en proyectos de datos.
- Fases ETL: `extract -> transform -> validate -> load`.
- Mini demostración de un flujo ETL en Python.

### Lección 01: Variables y tipos de datos
- Variables y reglas de nombrado.
- Tipos nativos (`str`, `int`, `float`, `bool`).
- Estructuras (`list`, `dict`, `tuple`, `set`).
- Conversión de tipos y validaciones básicas.

### Lección 02: Control de flujo
- Decisiones con `if / elif / else`.
- Iteraciones con `for` y `while`.
- `break` y `continue`.
- Comprensiones para transformar colecciones con código limpio.

### Lección 03: Funciones
- Definición de funciones reutilizables.
- Parámetros, valores por defecto, `args` y `kwargs`.
- `lambda`, `map`, `filter`.
- Introducción a decoradores y generadores.

### Lección 04: Manejo de archivos
- Lectura y escritura de archivos de texto.
- Trabajo con CSV y JSON.
- Uso correcto de `with` para manejo seguro de recursos.

### Lección 05: Manejo de errores
- `try / except / finally`.
- `raise` para reglas de negocio.
- Excepciones personalizadas.
- Logging para trazabilidad y soporte.

## 4. Metodología de trabajo

La dinámica del módulo combina explicación, práctica guiada y ejercicio autónomo:

1. **Concepto + ejemplo breve**
   Cada tema inicia con una explicación concreta y un ejemplo aplicado.

2. **Práctica guiada en notebooks**
   Usaremos notebooks para ejecutar y observar comportamiento paso a paso.

3. **Ejercicio por lección**
   Cada bloque tiene un `starter.py` para resolver problemas reales del tema.

4. **Discusión técnica de soluciones**
   Revisaremos enfoques, decisiones y oportunidades de mejora.

Esto no es solo “hacer que funcione”, sino desarrollar criterio para escribir código mantenible, claro y útil para producción.

## 5. Expectativas de aprendizaje

Al finalizar el módulo, cada asistente debería poder:

- Explicar la estructura de un script de Python orientado a datos.
- Manipular tipos y estructuras nativas con seguridad.
- Aplicar lógica condicional e iteraciones para transformar datos.
- Diseñar funciones reutilizables y legibles.
- Leer y escribir archivos comunes en pipelines.
- Implementar manejo de errores para aumentar confiabilidad.

Como resultado, tendrán una base real para avanzar luego hacia librerías y herramientas más avanzadas del ecosistema.
