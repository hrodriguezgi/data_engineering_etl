# Module 1 Exercises

This folder contains hands-on exercises aligned with Module 1 lessons.

## Current exercises
- `lesson_01_data_types/`: type conversion, collections, and summary metrics.
- `lesson_02_control_flow/`: conditional routing and loop-based data processing.
- `lesson_03_functions/`: reusable ETL function composition.
- `lesson_04_file_handling/`: CSV read/write plus JSON run summary.
- `lesson_05_error_handling/`: resilient parsing and error logging.

Each exercise folder includes:
- `README.md` with goal and acceptance criteria
- `starter.py` for students
