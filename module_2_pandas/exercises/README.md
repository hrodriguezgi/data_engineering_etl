# Module 2 Exercises

This folder contains hands-on exercises aligned with Module 2 lessons.

## Current exercises
- `lesson_01_intro_to_pandas/`: Series/DataFrame creation, calculated columns, and basic inspection.
- `lesson_02_data_cleaning/`: missing values, duplicates, type conversion, and quality checks.
- `lesson_03_data_transformation/`: derived columns, binning, and reshaping with pivot tables.
- `lesson_04_aggregations/`: groupby summaries, sorting, and business metrics.
- `lesson_05_merging_joining/`: joins with reference data plus matched/unmatched analysis.

Each exercise folder includes:
- `README.md` with goal and acceptance criteria
- `starter.py` for students
- `solution.py` with one possible implementation
